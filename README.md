# RoboWorld100 project page

An anonymous, dependency-free static site prepared for GitHub Pages.

## Publish at the account root

1. Rename the empty repository to `Projectpage2027.github.io`.
2. Copy the files in this directory to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`.
4. Check `https://projectpage2027.github.io/` after the Pages deployment finishes.

The current repository name, `roboworld100.github.io`, would instead publish at `https://projectpage2027.github.io/roboworld100.github.io/`.

## Before public release

- Review all wording and figures against the current manuscript. The figures were rendered from the existing project artwork; the website contains no manuscript PDF.
- Replace the resource placeholders only when the paper, code, and data are ready.
- Check the public Git history and commit author email. Use a pseudonymous profile and a GitHub `noreply` email for new commits if anonymity is required.
- Audit any future PDFs, images, and videos for visible identity details and embedded metadata.
- Confirm the applicable venue's anonymous project-page policy.

The site uses local assets and system fonts. It includes no analytics, third-party scripts, external images, or personal links.

The HTML contains a `noindex, nofollow` directive for the double-blind review period. This may reduce search indexing but does not make a public site or repository private. Remove the directive after the review period if public discovery is desired.
